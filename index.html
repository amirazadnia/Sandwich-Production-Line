Production line

Release rule: Order processing takes 30 seconds. Sandwich #1 starts at 0 s; subsequent sandwiches are released every 30 seconds. Watch where a persistent queue develops.
Each numbered yellow tile is one sandwich. Tiles physically advance through each station's waiting queue and into the machine when it becomes available. Orange queues indicate waiting WIP.
Capacity experiment: use the + / − controls at any station before running the line. Each added resource is an identical worker or machine operating in parallel.
Try adding capacity to the bottleneck first, then to a non-bottleneck. Observe whether total output changes and whether the bottleneck moves.

Calculate from the simulation

  1. What is the throughput time?
  2. What is the throughput efficiency?
  3. Which station is the bottleneck? Why?
  4. What is the cycle time?
  5. What is the capacity per hour?
  6. What throughput do you observe?
  7. Where and why does waiting/WIP develop?

Teacher / Reveal

Throughput time: Sandwich 1 takes 142.5 sec with no waiting. Later sandwiches take longer because waiting develops before Toast (e.g. #2 = 152.5 sec, #3 = 162.5 sec).

Throughput efficiency: Work content ÷ throughput time × 100. Work content is 142.5 sec, so Sandwich 1 = 100.0%, Sandwich 2 ≈ 93.4%, Sandwich 3 ≈ 87.7%, and efficiency falls as waiting increases.

Steady-state throughput: 1/40 sandwich/sec = 90 sandwiches/hour.

Queue: sandwiches reach Toast faster than Toast can process them. Waiting therefore accumulates immediately before Toast. The downstream Wrap station is fast enough relative to Toast and does not constrain output.

Insight: The processing work required for each sandwich does not change, but waiting increases as the queue grows. This increases throughput time and reduces throughput efficiency. The queue therefore provides a visible signal of the bottleneck.
